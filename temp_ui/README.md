# 🔥 Flame in Freefall (web app)

AI-powered fire safety insights from microgravity combustion data. A static website: plain
HTML, CSS and JavaScript. No Python, no Node, no install, no internet connection needed.
A neural network is trained inside your browser the first time you open the page.

## How to open it

**Option A: double-click.** Open `index.html` in Chrome, Edge or Firefox.

**Option B: XAMPP / Apache (`htdocs`).**
1. Copy this whole folder into `C:\xampp\htdocs\` (so you have `C:\xampp\htdocs\flame-in-freefall-web\index.html`).
2. Start Apache in the XAMPP control panel.
3. Visit `http://localhost/flame-in-freefall-web/`.

**Option C: any static host** (GitHub Pages, Netlify, Vercel): upload the folder as is.

The first load takes a few seconds while the model trains. The result is cached in your browser,
so later visits start instantly.

## Project layout

```
flame-in-freefall-web/
├── index.html          page structure
├── css/styles.css      theme and layout
└── js/
    ├── config.js       constants, ranges, thresholds
    ├── physics.js      reduced-order flammability model + fuel definitions
    ├── data.js         synthetic dataset generator, CSV import/export
    ├── nn.js           small neural network (MLP + Adam), no libraries
    ├── model.js        feature engineering, training, evaluation, caching
    ├── insights.js     predictions, what-if analysis, written recommendations
    ├── charts.js       canvas heatmap + SVG charts, no libraries
    └── main.js         controls, tabs and rendering
```

Scripts load in the order above and share one `FIF` namespace, so the app also works from
`file://` (browsers block ES modules there).

## What it does

| Tab | Content |
| --- | --- |
| Overview | Background, data notice, how to use it |
| Risk assessment | Risk level, flame-persistence probability, spread rate, written insights, same scenario at four gravity levels |
| Flammability map | Microgravity vs Earth maps of flame survival over oxygen and airflow, spread rate vs oxygen |
| AI model | Accuracy, ROC AUC, spread R² and error, feature importance, accuracy by gravity, retraining |
| Data | Outcome distribution, data preview, CSV download, **upload your own CSV** |

## Using real data

In the **Data** tab, upload a CSV with these columns and the model retrains on it:

`fuel, o2_percent, pressure_atm, flow_cm_s, gravity_g, thickness_mm, flame_sustained, spread_rate_mm_s`

Fuels: `cellulose`, `cotton_fiberglass`, `pmma`, `polyethylene`, `nomex`. `flame_sustained` is 0 or 1.
At least 200 rows are required. Problems are reported with the row number.

## Limitations

- The bundled dataset is **synthetic**, generated by a simplified physics model with illustrative
  parameters. It demonstrates the pipeline; it is not real experiment data.
- Independent educational project inspired by published microgravity combustion research.
  Not affiliated with or endorsed by NASA.
- Do not use the outputs for real safety decisions without validation against real experiments
  and review by qualified fire-safety engineers.
